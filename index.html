1. Introducción

Esta Política de Privacidad explica cómo SintaxisMD maneja la información y los documentos de sus usuarios.

SintaxisMD es una aplicación de escritorio para Windows que permite crear, editar, visualizar y exportar documentos Markdown.

La aplicación está diseñada para trabajar principalmente de forma local. No requiere crear una cuenta ni enviar documentos al desarrollador para utilizar sus funciones principales.

2. Información que recopilamos

SintaxisMD no incorpora mecanismos propios de recopilación externa de información personal.

En particular, la aplicación no implementa:

  • Registro de usuarios ni inicio de sesión.
  • Recopilación de nombres, teléfonos o correos electrónicos.
  • Telemetría o seguimiento del comportamiento.
  • Publicidad o perfiles publicitarios.
  • Servicios de analítica de uso.
  • Envío automático de informes de errores al desarrollador.
  • Transmisión de documentos a servidores propios.

El usuario puede escribir información personal dentro de sus documentos. Esta información se procesa y guarda localmente mediante las funciones de edición y almacenamiento.

3. Almacenamiento local de documentos

Los documentos creados o editados se guardan en la ubicación seleccionada por el usuario en su equipo.

SintaxisMD también conserva información de sesión para permitir la recuperación de las pestañas abiertas y del trabajo en curso.

El archivo de sesión puede incluir:

  • Texto de los documentos abiertos, incluso cambios todavía no guardados.
  • Rutas de los archivos.
  • Estado de las pestañas y selección.
  • Preferencias de visualización, idioma y tema.
  • Posición, tamaño y estado de la ventana.

En las instalaciones tradicionales, este archivo se encuentra en:

%APPDATA%\editor-md\session.json

El archivo se almacena en formato JSON y no está cifrado por SintaxisMD. Por ello, la protección depende también de los permisos y de la seguridad de la cuenta y del dispositivo Windows.

4. Conexiones a Internet y servicios externos

Las funciones principales de SintaxisMD pueden utilizarse sin conexión a Internet.

Sin embargo, existen dos situaciones en las que puede producirse tráfico externo:

  • Imágenes remotas: si un documento contiene una imagen alojada en una dirección HTTPS, la vista previa puede solicitarla al servidor que la aloja. Ese servidor podría recibir la dirección IP pública y datos técnicos habituales de la conexión.
  • Enlaces externos: cuando el usuario decide abrir un enlace HTTP o HTTPS, SintaxisMD lo entrega al navegador predeterminado del sistema.

SintaxisMD no controla las prácticas de privacidad de los servidores externos ni de los sitios web visitados.

5. Servicios y bibliotecas de terceros

La aplicación utiliza tecnologías y bibliotecas incorporadas localmente, entre ellas:

  • Electron para el entorno de escritorio.
  • CodeMirror para la edición de texto.
  • Marked para interpretar Markdown.
  • DOMPurify para sanear el contenido HTML de la vista previa.

La revisión del código no identificó SDK de publicidad, analítica, autenticación ni servicios de almacenamiento en la nube.

6. Cookies y almacenamiento web

El código propio de SintaxisMD no implementa el uso de cookies, localStorage, sessionStorage o IndexedDB como mecanismos de almacenamiento de datos del usuario.

La aplicación utiliza el entorno de Electron/Chromium. La posible caché interna del navegador al cargar recursos remotos no fue determinada mediante pruebas dinámicas.

7. Cuentas, licencias y pagos

SintaxisMD no implementa cuentas de usuario, inicio de sesión, activación mediante claves, validación propia de licencias ni pagos dentro de la aplicación.

Si la aplicación se adquiere mediante Microsoft Store, los procesos de compra, facturación y administración de la cuenta corresponden a Microsoft y se rigen por sus propias políticas.

8. Seguridad de la información

SintaxisMD incorpora medidas técnicas como aislamiento de contexto, ejecución restringida de código, validación de operaciones y saneamiento del contenido mostrado en la vista previa.

No obstante, los documentos y el archivo de sesión no cuentan con cifrado propio de la aplicación. Recomendamos mantener actualizado Windows y proteger el acceso al dispositivo mediante las herramientas de seguridad disponibles.

9. Conservación y eliminación de datos

Los documentos permanecen en las ubicaciones elegidas por el usuario hasta que este decida eliminarlos.

SintaxisMD no incluye actualmente una función para borrar todos los datos de la aplicación desde su interfaz.

En la instalación tradicional NSIS, los datos de usuario se conservan al desinstalar. Para eliminarlos, el usuario debe cerrar la aplicación y borrar manualmente la carpeta:

%APPDATA%\editor-md

El comportamiento exacto de eliminación de datos al desinstalar la versión AppX de Microsoft Store no ha sido determinado en esta revisión.

Si los documentos se guardan en carpetas sincronizadas, unidades de red o servicios de terceros, su sincronización y conservación dependen de esos servicios externos.

10. Privacidad de menores

SintaxisMD es una herramienta general de edición de documentos y no está diseñada específicamente para recopilar información de menores de 13 años.

No implementa registro de edad ni mecanismos específicos de recopilación de datos infantiles.

11. Cambios en esta política

Esta política podrá actualizarse cuando se incorporen nuevas funciones o cambie el tratamiento de información de la aplicación. La versión vigente estará disponible en esta página.

1. Introduction

This Privacy Policy explains how SintaxisMD handles users' information and documents.

SintaxisMD is a Windows desktop application for creating, editing, viewing and exporting Markdown documents.

The application is designed to work primarily locally. No account is required, and documents do not need to be sent to the developer to use its main features.

2. Information We Collect

SintaxisMD does not implement its own external personal information collection mechanisms.

Specifically, the application does not implement:

  • User registration or sign-in.
  • Collection of names, phone numbers or email addresses.
  • Telemetry or behavioral tracking.
  • Advertising or advertising profiles.
  • Usage analytics services.
  • Automatic error reports sent to the developer.
  • Uploads of documents to the developer's own servers.

Users may enter personal information in their documents. Such information is processed and stored locally through the application's editing and storage features.

3. Local Document Storage

Documents are saved to the location selected by the user on their device.

SintaxisMD also stores session information to restore open tabs and ongoing work.

The session file may include:

  • Text from open documents, including unsaved changes.
  • File paths.
  • Tab states and selections.
  • Display, language and theme preferences.
  • Window position, size and state.

In traditional desktop installations, this file is located at:

%APPDATA%\editor-md\session.json

The file is stored in JSON format and is not encrypted by SintaxisMD. Its protection therefore also depends on Windows account permissions and device security.

4. Internet Connections and External Services

SintaxisMD's main features can be used without an Internet connection.

However, external network traffic may occur in two situations:

  • Remote images: if a document contains an image hosted at an HTTPS address, the preview may request it from its hosting server. That server may receive the user's public IP address and ordinary technical connection information.
  • External links: when the user chooses to open an HTTP or HTTPS link, SintaxisMD passes it to the system's default browser.

SintaxisMD does not control the privacy practices of external servers or visited websites.

5. Third-Party Services and Libraries

The application uses locally bundled technologies and libraries, including:

  • Electron for the desktop environment.
  • CodeMirror for text editing.
  • Marked for Markdown processing.
  • DOMPurify to sanitize HTML preview content.

The code review did not identify advertising, analytics, authentication or cloud-storage SDKs.

6. Cookies and Web Storage

SintaxisMD's own code does not implement cookies, localStorage, sessionStorage or IndexedDB as user-data storage mechanisms.

The application uses the Electron/Chromium environment. Whether its internal cache stores remote resources was not determined through dynamic testing.

7. Accounts, Licenses and Payments

SintaxisMD does not implement user accounts, sign-in, product-key activation, its own license validation or in-app payments.

If the application is purchased through Microsoft Store, purchasing, billing and account management are handled by Microsoft and are subject to Microsoft's own policies.

8. Information Security

SintaxisMD includes technical safeguards such as context isolation, restricted code execution, operation validation and sanitization of preview content.

However, documents and the session file are not encrypted by the application. We recommend keeping Windows up to date and protecting device access using available security features.

9. Data Retention and Deletion

Documents remain in the locations selected by the user until the user deletes them.

SintaxisMD currently does not include an in-app feature to erase all application data.

With the traditional NSIS installation, user data is retained after uninstalling. To remove it, the user must close the application and manually delete:

%APPDATA%\editor-md

The exact data-removal behavior when uninstalling the Microsoft Store AppX version has not been determined in this review.

If documents are stored in synchronized folders, network drives or third-party services, their synchronization and retention are controlled by those external services.

10. Children's Privacy

SintaxisMD is a general-purpose document editing tool and is not specifically designed to collect personal information from children under 13.

It does not implement age registration or specific mechanisms for collecting children's data.

This policy may be updated when new features are introduced or the application's data practices change. The current version will be available on this page.
